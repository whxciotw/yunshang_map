# 常见问题与排查

## 卡片 / 面板

### 添加「定制地图」卡片后一直显示加载中

- v1.10.0 之前卡片要求长期令牌非空，未配置令牌时会一直加载；请升级到最新版。
- 升级后强制刷新浏览器缓存（`Ctrl+F5` / 手机端清除站点数据），再重新添加卡片。
- 检查 HA 日志（`设置 → 系统 → 日志`）是否有 `yunshang_map` 相关报错。

### 侧边栏没有「定制地图」入口

- 确认 `custom_components/yunshang_map` 目录完整、HA 已重启。
- 「设置 → 设备与服务 → 添加集成」中搜索「定制地图」并完成添加。
- 面板通过 iframe 加载，确认浏览器没有拦截 iframe。

### 卡片正常、面板白屏 / 反过来

- 两者共用 `www/index.html`，先确认静态资源可访问：`/yunshang_map_www/index.html?v=<版本号>`。
- 强制刷新缓存；确认集成版本与 `www/index.html`、`www/map.js` 中引用的版本号一致。

## 令牌 / Key / jscode

### 长期访问令牌是必须的吗？

不是。面板和卡片内嵌在 HA 页面里，会自动复用当前登录会话（WebSocket）；只有直接用浏览器打开地图页（脱离 HA）才需要长期令牌。令牌失效时建议在集成配置里清空。

### 为什么提示「未配置 jscode」

「回家路线 / 回家用时 / 地址反查」使用高德 JS API，需要高德 Key + 安全密钥 jscode。未配置时：

- 「回家路线」按钮置灰并显示原因；
- 轨迹位置地址反查显示「未配置 jscode」。

底图与轨迹回放不依赖 Key/jscode，可正常使用。配置后仍不可用，请检查：

1. Key 是否为 **Web 端（JS API）Key**，不是 Web 服务 Key。
2. jscode 是否与 Key 配套（2021-12 之后申请的 Key 需要）。
3. 高德控制台是否给该 Key 配置了域名白名单（如有，需要允许 HA 访问域名/IP）。
4. 浏览器控制台是否有高德 `INVALID_USER_KEY` / `USERKEY_PLAT_NOMATCH` 等错误。

### 回家路线按钮点了没反应

先看按钮是否置灰：置灰说明 Key/jscode 缺失。若未置灰但无路线：

- 设备当前是否在家/有效位置；
- 高德路线服务是否可达（网络）；
- 浏览器控制台是否有高德 API 报错。

## 底图

### OSM 显示 blocked / “Map data not yet available”

- 官方 `tile.openstreetmap.org` 对嵌入应用会返回 403；本项目已改用 OpenStreetMap France HOT 瓦片（v1.13+）。
- 若仍不可用：在「选项 → 可用底图类型」中取消勾选 `OSM 地图`，界面就不会再展示它。
- 之前 v1.12 曾使用 Esri 街道图，但在国内部分区域高缩放级别没有数据（灰块），已弃用。

### 切换底图后设备/轨迹整体偏移

- 这是修复过的问题：v1.11 之前切换底图时用新底图坐标系反算旧中心，会造成约 500 米漂移；升级即可。
- 不同坐标系（WGS84 / GCJ02 / BD09）之间本身存在几百米差异，属于正常；同一底图内点位与瓦片是对齐的。
- 百度瓦片缩放分辨率与高德/OSM 不同，同一 zoom 数字下比例会略有差异。

### 底图下拉里少了某些底图

检查「设置 → 设备与服务 → 定制地图 → 配置 → 可用底图类型」是否取消勾选；默认全选。

## 轨迹回放

### 轨迹动画不动 / 进度不变

- 轨迹至少需要 2 个历史点；确认该时间段内设备有运动记录（HA recorder 保留期内）。
- 检查是否已点击「播放」；设备长时间静止时轨迹位置可能不变，但时间/地址会随进度变化（按时间轴计算）。
- 多设备回放时检查是否选中了设备。

### 回放时设备实时图标消失

这是 v1.12 起的设计：回放轨迹时隐藏实时设备标记，只显示历史轨迹中的移动图标；点击「隐藏运动轨迹」后实时标记恢复。

### 设备数量 2 个 / 3 个来回变

- v1.13+ 已统一：列表保留「已配置的」或「曾经有坐标的」设备，暂未定位时显示「暂无位置」。
- 轨迹回放不再要求设备当前有坐标，只要历史里有记录即可回放。
- 如果设备确实被删除/重命名，选择状态会在下次渲染时清理。

### 拖动轨迹位置时地址不变

设备在该时间段内停在同一个位置时，地址本来就不变；可拖动到有移动的时间点验证。

## 主题 / 移动端

### 主题不跟随 HA

- 面板底部主题按钮选择「跟随系统」即跟随 HA 当前主题。
- 卡片 `theme_mode: auto` 跟随 HA；`light` / `dark` 强制指定。
- 若刚打开时短暂显示错误主题，属于 iframe 加载时序，通常很快自动纠正。

### 手机上抽屉/面板显示异常

- 手机端为底部抽屉：可上下拖动，吸附 45% / 68% / 90%，向下拖过 30% 关闭。
- 横屏或折叠屏展开时会切换为侧边布局。
- 若按钮/列表被遮挡，尝试更新到最新版并强制刷新；仍异常请提供机型、浏览器、截图。

## 数据不刷新

- 内嵌模式通过 WebSocket 获取数据；确认 HA 前端在线、WebSocket 未被代理断开。
- 独立打开页面时使用 REST + 长期令牌，令牌过期会停止刷新。
- 卡片历史轨迹默认每 60 秒刷新；设备位置约每 10 秒。
- HA recorder 未保留对应时间段时，历史查询为空。

## 获取日志

- HA：「设置 → 系统 → 日志」，搜索 `yunshang_map`。
- 浏览器：开发者工具 Console / Network，重点看 `yunshang_map_www` 静态资源、`history/history_during_period`、`tile.openstreetmap.fr`、`webapi.amap.com` 请求。
- 提交问题时请附：HA 版本、集成版本、底图类型、复现步骤、Console/日志截图。
